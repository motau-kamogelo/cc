1. ICE Tasks

Each attempted ICE task earns 2.5 percentage points. Four tasks earn a maximum of 10%. Select how many tasks you attempted.

ICE Tasks are worth up to 10% and the Summative is worth 35%. Set the weightings for Formative 1 and Formative 2 - check Module Outline(MO). Together, the two formative weightings must equal 55%.
